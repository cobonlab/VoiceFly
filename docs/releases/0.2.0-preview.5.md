# Voice Fly 0.2.0-preview.5 — automatic speech-service recovery

2026-10-14 · Speech service build 23 · Installer receipt 0.2.0.28

## 语音按键突然没反应后的维护更新

维护者遇到按住 Control 无法开始语音输入。现场检查发现服务一直停在上一段录音的收尾阶段；线程采样显示停止麦克风的调用卡在系统音频锁上。重启能恢复，但此前程序没有为关闭麦克风和整个收尾过程设置时间上限。

这次补上以下保护：

- 松开语音键后，收尾过程有 6 秒上限，覆盖等待采音线程退出、解码和文字处理。单独关闭麦克风的上限是 3 秒。
- 超时或麦克风清理报错时，服务进入“正在恢复”，退出卡住的进程，由 macOS 自动重新启动。不会在旧麦克风尚未释放时，假装空闲并打开下一段录音。
- 已经识别完成的文字先交回输入框，再清理麦克风。超时发生在文字完成以前时，不编造或冒充完整结果。
- 清理错误不再被悄悄忽略。状态文件包含正在执行的步骤和耗时；只保留最近一次固定类别的恢复记录，不记录录音、识别正文或会话文字。
- 旧会话的超时回调不能重启新会话；正常完成会取消检查。即使错误通知或记录被阻塞，也有单独的进程退出保护。

## Tests

- 180 focused service/audio/text tests passed on the maintainer's Python 3.13 environment, including blocked close, cleanup failure, stalled capture, session isolation, final-text-before-close and refusing overlapping recordings.
- 153 portable tests ran: 152 passed, one skipped. The portable suite includes a blocked-operation subprocess test that verifies exit 75 and a fresh subsequent process.
- 63 Swift tests passed. Keyboard behavior is unchanged from preview.4.
- The packaged model diagnostic verified five hashes, completed generated-silence inference and passed 24 normalization plus seven synthetic phonetic cases. It did not record or start the live service.
- An isolated launchd job running the packaged executable simulated a never-returning stop. macOS restarted it with a different PID and the next invocation reported readiness. It did not use a microphone or alter the production job.

The tested service was installed on the maintainer's Mac with a recoverable old-service backup, matching installed binary and valid signatures. The maintainer confirmed two consecutive Control-held dictations both worked and committed normally. Public-package validation results are recorded with the release assets. GitHub Actions separately reports checks for the exact source commit.

## Download and remaining limits

[Complete Apple Silicon installer](https://github.com/cobonlab/VoiceFly/releases/download/v0.2.0-preview.5/VoiceFly-0.2.0-preview.5-arm64.pkg) · [Installation instructions](../INSTALL.md)

The complete public installer contains the reviewed model/runtime, settings and six keyboard schemes. It supports Apple Silicon/macOS 26.4+, uses ad-hoc application signatures, and has no Apple Developer ID or notarization. Finish dictation/typing and select ABC before a full upgrade; save work and follow the manual logout/login instructions. The maintainer's service-only replacement is a separate local update and does not establish seamless full upgrades.

Native CoreAudio/device faults can still occur. This release bounds supported finalization/cleanup waits and requests automatic process recovery; it does not guarantee that an underlying audio failure can never recur or that every hardware fault can recover. Restart can take several seconds. If finalization itself times out, the uncommitted utterance may need to be spoken again. Independent first installation and broader device/host testing remain pending. The existing single-Space delay of up to 0.55 seconds with multi-tap learning remains unchanged.

Source and public packages exclude personal dictionaries, runtime ledgers, recovery records, recordings, installed applications and private backups.
