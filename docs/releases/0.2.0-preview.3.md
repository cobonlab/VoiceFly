# Voice Fly 0.2.0-preview.3 — complete installer preview

Released on October 1, 2026 (Asia/Shanghai).

## 可以直接下载安装的预览版

这次新增完整 `.pkg` 安装包，包含文字输入法、设置窗口、语音服务、运行环境和本地模型。用户不用自己编译，也不需要另装鼠须管、Python 或 Homebrew。

- 支持 M 系列 Mac、macOS 26.4 及以上。
- 全拼、小鹤双拼、自然码双拼、微软双拼、五笔 86 和五笔拼音混输。
- 保留设置窗口、共享个人词库、按键语音和已确认的麦克风风线图标。
- 没有付费的苹果开发者签名和公证；系统可能要求在“隐私与安全性”里选择“仍要打开”。
- 首次安装或完整升级后，保存工作，再手动注销并重新登录。安装程序不会自动注销。

## What changed

The source preview is now accompanied by a complete installable package. The staged frontend embeds glog/gflags, uses bundle-relative native dependency paths and carries reviewed public schemes/common resources. Unused optional plugin binaries from older local checkouts are omitted. The service includes its verified public streaming model, runtime dependencies and notices, while local pip acquisition paths are excluded.

Existing-install upgrades check idle dictation/ABC selection, wait for the frontend to exit and replace whole bundles with private backups. Full installation keeps the manual logout/login flow. The already verified artwork-only hot update remains a separate path; it does not establish seamless full upgrades.

## Checks and remaining work

- Six schemes produced 你好 candidates in disposable profiles using the extracted package's library, with Homebrew and the old development directory blocked.
- The extracted service verified five model hashes, ran generated-silence inference, passed 24 normalization cases and seven synthetic phonetic cases with network, Homebrew, the old development directory and system Python blocked. No recording or live-service startup was performed.
- Packaged bundle signatures, architectures, OS requirements, internal native links, script syntax and private-runtime exclusions were checked.
- The portable Python suite ran 144 tests on the maintainer's Mac, all passed. The preceding source preview's Swift core and macOS CI passed 60 tests; current exact-commit CI is reported separately by GitHub.

These are maintainer-machine/extracted-package checks. Independent first installation, real microphone/physical-key checks on another Mac, more host applications, older systems, Intel and coordinated full updates remain work. No public adoption, benchmarked speed improvement, Apple notarization or OpenAI endorsement is claimed.

## Source and licenses

Source, pinned resource provenance and model checksums accompany the release. The installer contains the public X-ASR int8 model under its upstream Apache-2.0 declaration and retains dependency notices. Source archives omit model weights; no personal dictionary, recording, runtime ledger or private backup is included.
