# Voice Fly 0.2.0-preview.4 — keyboard reliability update

2026-10-13 · Frontend build 27

## 根据日常使用反馈继续维护

使用中发现，空格和左右方向键在 Codex、Telegram、微信及网页的部分输入框里偶尔没有反应，长按方向键的表现也不一致。这次围绕这些反馈修正输入处理，并继续提供包含文字输入法、设置、语音运行环境和模型的完整安装包。

- 长按空格不再被误认成双击、三击；已经扣住的普通空格只补回一次。
- 补回空格时使用完整的文字提交流程，提高输入框兼容性。
- 没有待选文字时，左右键直接交给当前软件，避免多余的输入法界面刷新。
- 文字提交和输入源重新激活后，清掉旧的光标、选区记录。
- 修正安装器的桌面状态读取：在当前用户的桌面环境里检查 ABC 和语音空闲状态，避免拿到安装环境里的旧状态。

## 检查结果和仍待确认的部分

63 项 Swift 自动检查通过，包含 3 项新增的长按空格检查。原生 Release 编译和严格应用签名检查通过。修复版已安装到维护者电脑，保留了旧版备份；本机这次仅替换键盘输入部分，语音服务进程未重启。

这些结果不能代替逐个输入框的实际验证。Codex、Telegram、微信及网页中的故障是否全部消失，仍待真实使用确认。双击、三击空格功能继续保留；开启空格学词时，单次普通空格仍可能等待最多 0.55 秒。

Additional release checks: the local portable Python suite ran 144 tests on Python 3.14 (143 passed, one skipped). Extracted bundle signatures, Apple Silicon architecture, internal native dependencies and private-runtime exclusions passed. The packaged speech diagnostic verified five model hashes, completed generated-silence inference and passed 24 normalization plus seven synthetic phonetic cases without opening a microphone or starting the service. The speech bundle's extracted files match the previously reviewed public distribution. GitHub CI additionally checks Python 3.13 and Swift.
