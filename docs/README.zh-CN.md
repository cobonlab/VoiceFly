# Voice Fly 本地语音与文字输入法

## 为什么做这个输入法

和 AI 合作时，我们经常需要输入很长的想法、需求、背景和修改意见。Simon 在日常使用中发现，键盘打字跟不上表达，会打断思路，也拖慢项目推进。所以我们专门为苹果电脑做这个本地语音转文字输入法，让想法能更快、更顺地变成文字。

目前的设计重点有三件事：

1. 按住实体 Control 键说话，松开后完成输入，减少寻找和点击麦克风按钮的动作。
2. 双击空格，再按数字选择词语长度，明确保存行业用语和经常出现的名字，供后续识别使用。
3. 文字和语音共用个人词条，让打字和说话都能用到同一份熟悉的词库。普通打字频率不会未经明确保存就自动改变语音识别。

这些设计来自实际使用需求；目前还没有公开的速度对照测试，也不宣称其他输入工具都没有类似功能。

## 当前版本

Voice Fly 把 Rime 文字输入和本地中英文语音识别接到 macOS 原生输入法里。可以打字，也可以按住 Control 说话，边说边显示，松键后提交；明确保存的个人词可以用于文字和语音。

0.2.0-preview.2 是新的源码预览版，已加入真正的设置窗口、六种文字输入方案、本机个人词库和一体安装工具。此次提供源码和公共资源，不附可直接安装的应用包。本机构建的应用面向 Apple Silicon、macOS 26.4 及以上；还没有苹果开发者签名和公证，其他系统版本、更多应用里的实际表现以及新用户独立安装仍需要继续验证。边界和安装方法见[安装说明](INSTALL.md)。

这次还统一了 Voice Fly 名称，换上白色圆角底的麦克风与风线图标，设置窗口不会再多出 Dock 图标。Simon 已在自己的 Mac 上确认最终图标、文字和 Control 语音正常，最后的图标更新没有注销或关闭其他应用。这个结果只代表已验证的这台电脑。详情见[本次更新说明](releases/0.2.0-preview.2.md)。

## 已有成果

- 原生输入法里边说边显示、松键提交。
- 全拼、小鹤双拼、自然码双拼、微软双拼、五笔 86、五笔拼音混输。
- 可以调整候选数量、简繁体、符号、语音按键和麦克风的设置窗口。
- 可以查看、编辑读音、删除、导入和导出个人词库。
- 明确保存个人词，区分普通选词统计和语音学习。
- 每次录音重新跟随系统麦克风，采音和识别分别处理。
- 处理数字、日期、编号，并保护普通成语和表达。
- 围绕学词、录音状态和输入交互积累了 Swift、Python 回归测试。

核心语音识别在本机运行，不需要 OpenAI 密钥。实验性的第二模型定稿功能默认关闭；仓库不包含维护者的私人词库、录音、聊天或模型文件。
