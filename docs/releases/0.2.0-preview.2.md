# Voice Fly 0.2.0-preview.2

Released October 1, 2026 (Asia/Shanghai). This is a public **source preview** for review and contribution. The release contains code, original artwork and licensed public Rime resources; it does not include a consumer application installer or speech model weights.

## 从真实需求继续补齐

Voice Fly 为 Mac 上的大量 AI 文字交流而做：按住实体键说话，双击空格后用数字明确保存热词，文字和语音共用个人词库。本次在第一份公开源码基础上，补齐设置、多种文字输入方式和维护工具。

- **真正的设置窗口**：选择文字方案、候选数量、简繁体、标点、语音按键和麦克风。打开设置不再多出 Dock 图标。
- **六种中文输入方式**：全拼、小鹤双拼、自然码双拼、微软双拼、五笔 86、五笔拼音混输，使用有来源和许可记录的公共 Rime 资源。
- **本机个人词库**：默认不依赖 iCloud，支持查看、读音编辑、删除和导入导出；旧记录迁移保留备份。
- **独立品牌**：当前应用和服务统一为 Voice Fly，采用确认好的白色圆角底、麦克风与风线图标。历史名称只保留在迁移代码和来源记录中。
- **更新与恢复**：加入组合打包、备份、失败恢复和卸载源码。图标更新在维护者本机已经验证无需注销；第一次安装和完整组件升级仍按文档处理。

## What changed

Native settings and six keyboard schemes make the source less dependent on the maintainer's personal setup. Shared terms now have a local ledger and editable pronunciation. Packaging uses named public resources rather than copying an installed personal application. Original microphone-and-wind artwork and an accessory settings window improve the application identity.

The existing-install artwork update preserves source approval and speech, replaces whole signed bundles with recoverable backups, and refreshes only the menu display. The final badge uses vector alpha cutouts because the earlier opaque black-on-white image appeared as a blank white rectangle in the native menu. The geometry of the approved mark is unchanged.

## Validation

- Current source, Python 3.13.7 / NumPy 2.5.2: **144 tests run, 143 passed, one skipped**. No ASR model or live microphone was loaded.
- Separate Swift scratch build: **60 tests passed**. These exercise core interaction, settings, shared terms and local data handling.
- Public schema checksums matched their pinned upstream inventory; licenses and authors are retained.
- Six Rime schemes previously produced candidates in disposable profiles. This does not prove every scheme's full physical-key and dictation workflow on every host application.
- The maintainer confirmed final build 26's native badge, Chinese typing and Control dictation on **macOS 26.6.2 Apple Silicon**, without logout or closing other applications. Speech remained running through the artwork update.
- Source and release inputs exclude personal dictionaries, runtime ledgers, recordings, private chat, model weights, credentials, installed applications and backups.

GitHub Actions independently checks the portable Python subset and Swift package. Its status is published with the release's commit; local results do not replace that check.

## Remaining work

The locally built full bundle requires Apple Silicon/macOS 26.4+. Apple Developer ID signing/notarization, independent new-user installation, a full clean-machine build, broader host/device testing and general full-component hot upgrades remain unverified. Optional synchronization is not implemented. Automatic updating is disabled; the new artwork updater is a separate documented trial path.

No public adoption, speed improvement, OpenAI endorsement or support award is claimed. The contribution is the maintained Rime/local-ASR input workflow and integration, not a newly trained speech model.
