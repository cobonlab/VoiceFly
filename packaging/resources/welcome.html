欢迎安装 Voice Fly

适用于 M 系列 Mac，要求 macOS 26.4 或更新版本。安装包包含文字输入、设置窗口、语音服务和本地语音模型。无需另装鼠须管、Python 或 Homebrew，也无需 API 密钥。

本预览版没有苹果 Developer ID 签名或公证。请只从 cobonlab/VoiceFly 的 GitHub 发布页面下载。如果 macOS 拦住安装，请到“系统设置 → 隐私与安全性”查看是否有“仍要打开”选项。

如果你已安装 Voice Fly，请先结束文字和语音输入，再切换到 ABC。首次安装或完整升级后，请保存工作，再手动注销并重新登录。安装程序不会替你注销。

安装后需要允许启用 Voice Fly 输入法，并允许 Voice Fly Service 使用麦克风。

Apple Silicon, macOS 26.4+. All runtime components and the local model are included. This preview is not Developer ID signed or notarized. Save your work and log out/in manually after installation; the installer will not log you out.
